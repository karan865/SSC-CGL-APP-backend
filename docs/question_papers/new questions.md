#### Q1. If $x + \frac{1}{x} = 5$, find the value of $x^5 + \frac{1}{x^5}$.
- **(A)** 2525
- **(B)** 2520
- **(C)** 2530
- **(D)** 2500

**Answer:** (A) 2525
**Explanation:**  
$x^2 + \frac{1}{x^2} = 5^2 - 2 = 23$  
$x^3 + \frac{1}{x^3} = 5^3 - 3(5) = 110$  
$(x^2 + \frac{1}{x^2})(x^3 + \frac{1}{x^3}) = x^5 + \frac{1}{x^5} + (x + \frac{1}{x})$  
$23 \times 110 = x^5 + \frac{1}{x^5} + 5 \implies 2530 - 5 = 2525$.

#### Q2. If $a + b + c = 7$ and $a^3 + b^3 + c^3 - 3abc = 301$, find the value of $ab + bc + ca$.
- **(A)** 4
- **(B)** 2
- **(C)** -2
- **(D)** 6

**Answer:** (B) 2
**Explanation:**  
$a^3 + b^3 + c^3 - 3abc = (a + b + c)[(a + b + c)^2 - 3(ab + bc + ca)]$  
$301 = 7 \times [49 - 3k] \implies 43 = 49 - 3k \implies 3k = 6 \implies k = 2$.

#### Q3. If $x^4 + x^2y^2 + y^4 = 21$ and $x^2 + xy + y^2 = 7$, find the value of $\frac{1}{x^2} + \frac{1}{y^2}$.
- **(A)** 5/4
- **(B)** 5/2
- **(C)** 7/4
- **(D)** 3/2

**Answer:** (A) 5/4
**Explanation:**  
$(x^2 + xy + y^2)(x^2 - xy + y^2) = x^4 + x^2y^2 + y^4 \implies 7 \times (x^2 - xy + y^2) = 21 \implies x^2 - xy + y^2 = 3$.  
Adding the two equations: $2(x^2 + y^2) = 10 \implies x^2 + y^2 = 5$.  
Subtracting gives: $2xy = 4 \implies xy = 2 \implies x^2y^2 = 4$.  
Therefore, $\frac{1}{x^2} + \frac{1}{y^2} = \frac{x^2 + y^2}{x^2y^2} = \frac{5}{4}$.

#### Q4. If $x = 2 + \sqrt{3}$, find the value of $\frac{x^6 + x^4 + x^2 + 1}{x^3}$.
- **(A)** 52
- **(B)** 56
- **(C)** 64
- **(D)** 48

**Answer:** (B) 56
**Explanation:**  
$\frac{x^6 + x^4 + x^2 + 1}{x^3} = (x^3 + \frac{1}{x^3}) + (x + \frac{1}{x})$.  
Since $x = 2 + \sqrt{3}$, $\frac{1}{x} = 2 - \sqrt{3} \implies x + \frac{1}{x} = 4$.  
$x^3 + \frac{1}{x^3} = 4^3 - 3(4) = 52$.  
Total $= 52 + 4 = 56$.

#### Q6. If $a^2 + b^2 + c^2 + 96 = 8(a + b - 2c)$, find the value of $\sqrt{ab - bc + ca}$.
- **(A)** 6
- **(B)** 4
- **(C)** 8
- **(D)** 2

**Answer:** (B) 4
**Explanation:**  
$(a^2 - 8a + 16) + (b^2 - 8b + 16) + (c^2 + 16c + 64) = 0 \implies (a - 4)^2 + (b - 4)^2 + (c + 8)^2 = 0$.  
Thus $a = 4, b = 4, c = -8$.  
$\sqrt{ab - bc + ca} = \sqrt{16 - (-32) + (-32)} = \sqrt{16} = 4$.

#### Q7. If $x = \sqrt{5} + 2$, find the value of $x^3 - \frac{1}{x^3}$.
- **(A)** 76

- **(C)** 72
- **(D)** $34\sqrt{5}$

**Answer:** (A) 76
**Explanation:**

#### Q8. If $x = 99, y = 100, z = 101$, find the value of $x^2 + y^2 + z^2 - xy - yz - zx$.
- **(A)** 1
- **(B)** 3
- **(C)** 0
- **(D)** 4

**Answer:** (B) 3
**Explanation:**  
$x^2 + y^2 + z^2 - xy - yz - zx = \frac{1}{2}[(x - y)^2 + (y - z)^2 + (z - x)^2] = \frac{1}{2}[(-1)^2 + (-1)^2 + (2)^2] = \frac{1}{2}(1 + 1 + 4) = 3$.

#### Q9. If $x + y = 3$ and $x^2 + y^2 = 101$, find the value of $x^3 + y^3$.
- **(A)** 417
- **(B)** 427
- **(C)** 437
- **(D)** 441

**Answer:** (D) 441
**Explanation:**  
$(x + y)^2 = x^2 + y^2 + 2xy \implies 9 = 101 + 2xy \implies 2xy = -92 \implies xy = -46$.  
$x^3 + y^3 = (x + y)(x^2 - xy + y^2) = 3 \times [101 - (-46)] = 3 \times 147 = 441$.

#### Q10. If $\frac{x}{y} + \frac{y}{x} = -1$ (where $x, y \neq 0$), find the value of $x^3 - y^3$.

#### Q22. Fresh grapes contain 80% water by weight, while dried grapes contain 15% water by weight. How many kilograms of dried grapes can be obtained from 68 kg of fresh grapes?
- **(A)** 15 kg
- **(B)** 16 kg
- **(C)** 17 kg
- **(D)** 18 kg

**Answer:** (B) 16 kg
**Explanation:**

$\text{Weight of dried grapes} = \frac{13.6}{0.85} = 16\text{ kg}$.

#### Q23. A and B jointly start a business. A invests ₹60,000 for 8 months and B invests ₹80,000 for 6 months. A receives 15% of the total profit for managing the business. If the total profit is ₹40,000, find B's share.
- **(A)** ₹17,000
- **(B)** ₹16,000
- **(C)** ₹15,000
- **(D)** ₹18,000

**Answer:** (A) ₹17,000
**Explanation:**  
Managing commission to A $= 15\% \text{ of } 40,000 = ₹6,000$.  
Remaining profit $= ₹34,000$.  
Ratio of investment $= (60,000 \times 8) : (80,000 \times 6) = 480,000 : 480,000 = 1 : 1$.  
B's share $= \frac{34,000}{2} = ₹17,000$.

#### Q25. Two trains of equal length are running on parallel tracks in the same direction at 54 km/h and 42 km/h. The faster train completely passes the slower train in 60 seconds. Find the length of each train.
- **(A)** 100 m
